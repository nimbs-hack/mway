# Mission planner

Requires [Bun](https://bun.sh) and [Go](https://go.dev/dl/) 1.24 or newer.

## Run locally

```sh
bun install
bun run dev
```

Open the URL printed in the terminal. Vite starts the Go API automatically.

## Build and run

```sh
bun run build
bun run start
```

Open http://localhost:3000.
